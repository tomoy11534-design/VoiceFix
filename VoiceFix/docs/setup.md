# VoiceFix 公開までの手順

すべて無料でできます。所要時間は30分ほどです。

## 1. 投稿を受け取るスプレッドシートを作る

1. [Google スプレッドシート](https://sheets.new) で新しいシートを作る（名前は「VoiceFix 投稿」など）
2. メニューの「拡張機能」→「Apps Script」を開く
3. 最初から入っているコードをすべて消し、`gas/code.gs` の中身を貼り付ける
4. `SHARED_TOKEN = 'change-me'` の `change-me` を、推測されにくい好きな文字列に変える（例: `voicefix-8k2m9x`）
5. 保存（💾）する

## 2. ウェブアプリとして公開する

1. 右上の「デプロイ」→「新しいデプロイ」
2. 種類の選択（⚙）で「ウェブアプリ」を選ぶ
3. 次のように設定して「デプロイ」
   - 次のユーザーとして実行: **自分**
   - アクセスできるユーザー: **全員**
4. Google アカウントへのアクセス許可を求められたら許可する
   （「このアプリは確認されていません」と出たら「詳細」→「（安全ではないページ）に移動」）
5. 表示された **ウェブアプリのURL**（`https://script.google.com/macros/s/.../exec`）をコピーする

## 3. アプリに設定を書き込む

`app.js` の先頭を書き換える。

```js
const ENDPOINT_URL = 'ここに2-5でコピーしたURL';
const SHARED_TOKEN = 'ここに1-4で決めた合言葉';
```

## 4. GitHub Pages で公開する

1. GitHub で新しいリポジトリを作る（例: `voicefix`）
2. このフォルダのファイル（`index.html`, `style.css`, `app.js`, `service-worker.js`, `manifest.json`, `icon.svg`）をアップロードする
3. リポジトリの「Settings」→「Pages」→ Branch を `main` / `/(root)` にして保存
4. 数分後、`https://（ユーザー名）.github.io/voicefix/` で開けるようになる

## 5. 動作確認

1. スマホで公開URLを開き、試しに1件投稿する
2. スプレッドシートに「投稿」シートができて、1行追加されていればOK
3. 確認用の投稿はスプレッドシートから消してよい（スマホ側の記録は残る）

## 6. 知人に送る

LINEなどでURLを送り、次のことを伝える。

- 最初に出る画面で「カレンダーに登録」を押すと、毎日通知が来る
- ホーム画面に追加するとアプリのように使える
- 初めてマイクを使うときに「マイクを許可しますか？」と出るので「許可」を押す

## あとからアプリを直したとき

- `app.js` などを直して GitHub にアップロードし直すだけでOK
- `gas/code.gs` を直したときは、Apps Script で「デプロイ」→「デプロイを管理」→ 鉛筆マーク →「バージョン: 新バージョン」→「デプロイ」（URLは変わらない）
