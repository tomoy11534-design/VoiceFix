# VoiceFix 要件定義書（v0.3）

最終更新: 2026-10-15

---

## 1. 概要

### 1.1 コンセプト
**「今日の困りごと、ひとこと話すだけ」**
知人1人に毎日の困りごとを声で投稿してもらい、運営者（自分）が「その人が何に困っているのか」を知るためのアプリ。

### 1.2 目的
1. **毎日続けてもらう**ことを最優先にする（入力の手間を最小に、続けたくなる仕組みを入れる）
2. 毎日の投稿を集めて、困りごとの傾向（分野、頻度、よく出る言葉）を把握する
3. **運用費0円**で作って運用する

### 1.3 利用者
| 立場 | 人数 | 説明 |
|---|---|---|
| 投稿者 | 1人（知人） | 困りごとを音声で投稿する。ログイン・属性入力なし |
| 運営者 | 1人（自分） | 投稿をスプレッドシートで見て、傾向を把握する |

---

## 2. スコープ

### 2.1 MVP（v1.0）で実現すること
- 音声入力（＋手入力の併用）による困りごとの投稿（分野は限定しない）
- 毎日続けてもらうための仕組み（連続日数、カレンダー、リマインダー）
- 投稿者が自分の履歴と困りごとランキングを見られる
- 投稿を運営者のスプレッドシートに保存する

### 2.2 対象外
- AIによる解決策の提示・自動分類（有料APIが必要なため。集めたデータを手動でAIに分析させるのは可）
- 年代などの属性入力
- ログイン・複数ユーザー対応
- 音声読み上げ

## 3. 機能要件

### F-01 音声入力（＋手入力）
| 項目 | 内容 |
|---|---|
| 起動 | アプリを開いたらすぐ投稿画面。マイクボタンが一番大きく、画面中央にある |
| 操作 | マイクボタンをタップで録音開始、もう一度タップで終了 |
| 文字起こし | ブラウザ標準の音声認識（Web Speech API）で、入力欄にリアルタイムで書き込む |
| 手入力 | 入力欄はいつでもキーボードで入力・修正できる。音声と手入力は混ぜて使える。音声はカーソル位置に追記する |
| 代替手段 | 音声認識が使えないブラウザではマイクボタンを隠し、手入力だけで使える |

### F-02 分野・困り度の選択（任意）
- 送信前に分野と困り度をワンタップで選べる。**選ばなくても送信できる**（手間を増やさないため）
- 分野: 住まい／家電・機器／お金・手続き／健康／人間関係／仕事・学校／デジタル／買い物／移動／その他
- 困り度: 😐 ちょっと／😣 かなり／😱 すごく

### F-03 送信
- 「送信」で運営者のスプレッドシートに保存する
- 1日に何件でも投稿できる
- 通信できないときは端末に一時保存し、次に開いたときに自動で再送する

### F-04 毎日続けてもらう仕組み
| 仕組み | 内容 |
|---|---|
| 連続日数 | 投稿画面に「🔥 5日連続」を表示する |
| カレンダー | 投稿した日に印がつく月カレンダー（スタンプカード風） |
| 送信後のひとこと | 「今日も記録できました」など、毎回少しずつ違う言葉で褒める |
| 節目のお祝い | 7日・30日・100日連続などで特別な表示を出す |
| 「困りごとなし」ボタン | 困りごとがない日もワンタップで記録でき、連続日数が途切れない |
| リマインダー | 毎日決まった時刻に通知が出るよう、スマホのカレンダーに登録できるファイル（.ics）を配布する（無料・サーバー不要） |
| ホーム画面に追加 | 初回にホーム画面へのアイコン追加を案内し、アプリのようにワンタップで開けるようにする |

### F-05 自分の履歴
- 自分の投稿を日付ごとに一覧表示する（端末内にも保存）

### F-06 困りごとランキング
- 自分の投稿の集計をランキングで見られる（今週／今月／全期間で切り替え）
- 分野別ランキング
- よく出る言葉ランキング（上位10語。ブラウザ標準の `Intl.Segmenter` で単語に分け、「こと」「ある」などのありふれた言葉は除外）
- 端末内のデータで集計する（通信不要）

### F-07 運営者のデータ閲覧
- 全投稿をGoogleスプレッドシートで見られる（日時、本文、分野、困り度、入力方法）
- 並べ替え・絞り込み・グラフはスプレッドシートの機能を使う（専用の集計画面は作らない）

## 4. 非機能要件

| 分類 | 要件 |
|---|---|
| 費用 | 開発・運用ともに0円 |
| 対応環境 | スマホ優先（Android Chrome / iOS Safari）。PWAでホーム画面に追加できる |
| 操作性 | アプリを開いてから投稿完了まで3タップ以内（マイク→話す→マイク→送信）。ボタンは最低48px |
| プライバシー | 音声そのものは保存しない（文字だけ保存）。初回に「投稿内容は運営者（○○）に届きます」と伝える |
| セキュリティ | 通信はHTTPS。データ送信先のURLは推測されにくいものにする |

## 5. 無料で作る技術構成

| 役割 | 使うもの | 備考 |
|---|---|---|
| 画面 | HTML / CSS / JavaScript（PWA） | フレームワークなし |
| 音声認識 | Web Speech API（ブラウザ標準） | Chrome・Safari は音声を Google／Apple のサーバーで文字起こしする |
| 公開 | GitHub Pages | HTTPSが標準（マイク利用にはHTTPSが必須） |
| データ保存 | Google スプレッドシート ＋ Google Apps Script | サーバー不要。Apps Script が投稿を受け取り1行ずつ保存 |
| 端末内保存 | localStorage | 履歴、連続日数、未送信データ |
| リマインダー | .ics ファイル（毎日繰り返す予定） | スマホ標準のカレンダーアプリが通知してくれる |

### 構成図
```
[知人のスマホ]
  ├ 音声 → Web Speech API → 文字（手入力も可）
  ├ 履歴・連続日数・ランキングは端末内で処理
  └ 送信 ──HTTPS──▶ [Google Apps Script] ──▶ [Google スプレッドシート] ◀── 運営者が閲覧
```

## 6. 画面一覧

| ID | 画面名 | 主な要素 |
|---|---|---|
| S-01 | はじめに（初回のみ） | 使い方の説明、投稿が運営者に届く旨、ホーム画面追加の案内、リマインダー登録ボタン |
| S-02 | 投稿（ホーム） | 連続日数、マイクボタン、入力欄、分野・困り度（任意）、送信、「困りごとなし」ボタン |
| S-03 | 記録 | 月カレンダー（投稿日に印）、日付ごとの投稿一覧 |
| S-04 | ランキング | 分野別ランキング、よく出る言葉ランキング、期間切り替え |

### 投稿の流れ
```
[アプリを開く] → [マイクをタップして話す ／ 手入力] → [送信]
  → 「🔥 6日連続！今日も記録できました」 → [S-02 に戻る]
```

---

## 7. データ項目

**投稿（スプレッドシートの1行）**
| 列 | 型 | 説明 |
|---|---|---|
| id | string | 投稿ID |
| createdAt | datetime | 投稿日時 |
| text | string | 困りごとの本文（「困りごとなし」の日は空） |
| category | string | 分野（未選択なら空） |
| level | number | 困り度 1〜3（未選択なら空） |
| inputMethod | string | voice / text / mixed / none |

## 8. 成功指標

- 連続投稿日数（目標: 30日）
- 1か月のうち投稿した日数の割合（目標: 80%以上）
- 音声入力の利用率

---

## 9. リスクと対策

| リスク | 対策 |
|---|---|
| 続かない・忘れる | 連続日数、カレンダー、リマインダー、「困りごとなし」ボタン |
| 音声認識の精度（方言・雑音） | 送信前に手入力で修正できる |
| 非対応ブラウザ | 手入力だけで使えるように切り替える |
| 通信できない | 端末に一時保存して自動で再送 |
| 機種変更でスマホ内の記録が消える | 運営者側のスプレッドシートには全件残る |
